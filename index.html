📖 영양소와 소화 효소 반응 도감

🍞 탄수화물 소화 과정

• 녹말 + [아밀레이스] ➔ 엿당
• 엿당 + [말테이스] ➔ 포도당 (최종)

🥩 단백질 소화 과정

• 단백질 + [펩신] 또는 [트립신] ➔ 중간 단백질(폴리펩타이드)
• 중간 단백질 + [펩티데이스] ➔ 아미노산 (최종)

🧈 지방 소화 과정

• 지방 + [라이페이스] ➔ 지방산과 모노글리세라이드 (최종)

💡 퍼즐 공략 팁: 어떤 문은 분해되기 전의 '녹말'이나 '단백질'을 요구하고, 어떤 문은 분해된 후의 '엿당'이나 '아미노산'을 요구합니다. 방 안의 효소를 줍기 전에 어느 문을 먼저 열어야 할지 순서를 잘 생각하세요!
